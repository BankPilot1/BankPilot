# BankPilot MVP

微信式个人金融 Agent 原型。使用 Node.js 原生 HTTP 服务与无构建前端，无需安装第三方依赖。

团队演示：https://bankpilot-team-demo.hokkaipro.chatgpt.site （公开链接，仅模拟数据，每个浏览器独立沙箱）。已启用 DeepSeek 真实 AI 分析，无需登录或访问码；保留可配置的 OpenAI 兼容接口。配置方法见 [AI 与上线](docs/AI与上线.md)。

## 启动

要求 Node.js 20 或更新版本。在项目目录执行：

```powershell
npm.cmd start
```

访问 http://localhost:3107 。默认只监听本机。可通过 `PORT` 环境变量更换端口。

```powershell
npm.cmd test
```

## 当前可体验

- 会话、卡包、任务、动态四个视图；桌面三栏和移动布局。
- 四个模拟账户、从 Sparkov 导入的六个月消费、按消费推导的模拟信用卡账单及独立配置的三项代扣。
- 单卡/群组/全局余额查询、消费分析、账单汇总与资金充足性分析。
- “给小王转 200 元”：同名澄清、黄色确认、真实更新模拟余额/流水。
- “给小李转 1200 元”：红色验证，演示验证码 `246810`。
- 订阅查询确认、模拟代扣取消、任务状态及审计。
- 重复确认幂等、执行时累计额度复核、三次验证失败锁定任务、15 分钟确认有效期。
- 状态保存到 `.data/state.json`，服务重启可保留。设置抽屉可重置演示。

## 预留接口

前端统一通过 `public/api.js` 调用，业务实现位于 `src/bank.mjs`。后续接入数据源时在服务端新增银行适配器；不要让模型直接写账户余额。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/bootstrap` | 演示账户、会话、任务、代扣与审计快照 |
| GET | `/api/transactions?scope=all` | 按范围读取流水 |
| POST | `/api/chat` | `{scope,text,action?}` 意图与业务规划 |
| POST | `/api/tasks/confirm` | `{taskId,code?}` 后端校验并执行 |
| POST | `/api/tasks/cancel` | `{taskId}` 取消未执行任务 |
| POST | `/api/demo/reset` | 重置演示数据 |

scope 支持 `all`、`savings`、`credits`、`repayment` 及账户 ID。action 为结构化 UI 选择，仅支持已定义类型，不能绕过确认接口。

## 当前边界

已接入 Sparkov 公开合成交易数据，并实现兼容 OpenAI Chat Completions 的模型接入层。填写服务端 `.env` 后可启用模型意图理解和分析；未配置时使用规则演示。DeepSeek 已完成本地与公网调用验证。尚未接入真实银行接口，资金与验证均为模拟，不能作为生产金融服务使用。

数据下载位置、清洗复现方式与演示转换说明见 [data/README.md](data/README.md)。原始全量数据保存在 `data/raw/sparkov/` 并排除出 Git，精简处理样本随项目保存。消费分析的“本月”按数据导入基准月计算，更新基准日须重新导入并重启。

自定义建群、群公告编辑、定时执行、语音、真实验证、人工客服和代码沙箱尚未实现；预设“每月还款”群仅提供留存规则下的分析。动态为固定演示提示。数据为独立的历史流水样本及初始余额快照，不是完整可对账账本。

后续建议顺序：确定统一数据模型及数据来源 → 银行适配层与账本 → 结构化模型工具调用 → 授权/身份与持久数据库 → 定时编排与人工接管。
